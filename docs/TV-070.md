# Adam TV 0.7.0

## Features and design

- TV supports 1–4 players. Multiplayer uses separate vertical play panes, with a score and player label above each pane. Race and family cooperation retain four players through the 15-stage journey.
- Each player can choose an outfit, backpack, and hat. The selection screen preserves focus after a choice and saves wardrobe selections.
- One TV remote can be assigned to one player; the other players use separate gamepads. Remote movement affects only its assigned player. A or Start joins an unassigned gamepad.
- Menu controls explicitly handle A to activate and B to return; during play B pauses, and while paused it resumes. The left stick moves menu focus with a dead zone and repeat interval, and steers during play.
- Profile cards provide recognizable player identity and large selection targets. The design reference is the [Netflix profile-card screen on Mobbin](https://mobbin.com/screens/9b0cfc61-f627-4691-b3a8-b4ea35110aad), adapted to Adam’s Arabic interface and illustrated palette.
- Fresh installs default to balanced 1080p TV rendering. Settings also offer native display resolution and economical 720p. Previously saved resolution choices remain effective.
- Power labels use larger text with three or four players; the visual review’s readability concern was resolved with this change.

## Updates

The in-app update screen checks GitHub releases for a newer semantic version and the expected Android APK. It requires the release download URL, file-size bounds, and a SHA-256 digest. Android downloads the APK inside the app, verifies its SHA-256, and opens the native system installer. Android may first require permission to install from this app; the user then returns and selects install again.

iOS does not directly install GitHub APKs or updates. Its update screen opens GitHub release information; iPhone installation requires Apple distribution.

## Validation and limits

The coordinating agent reported passing UI, simulation, feature, four-player journey/route, and controller checks, plus real GitHub metadata retrieval and APK download/hash verification. `tests/test_four_updates.gd` covers version comparison, rejected update metadata, four visible panes, isolated remote input, race/cooperative progression, all cooperative routes, malformed responses, and termination of a live GitHub check.

On an Android emulator, the actual native installer opened and a same-version package update succeeded. This validates that installation path, but does not demonstrate a released newer-version upgrade on physical TV hardware.

A four-player desktop run measured 58 fps with a 22.201 ms p95 frame time. This is desktop evidence, not a TV hardware performance guarantee. No physical NVIDIA Shield or Xiaomi TV device was validated. The original Mi TV Stick’s GLES2-only graphics support is incompatible with this Godot build.

Implementation reviewed: `scripts/main.gd`, `scripts/stage.gd`, `scripts/updater.gd`, and `tests/test_four_updates.gd`.
